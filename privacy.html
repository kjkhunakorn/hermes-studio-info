Hermes Studio — ปรับปรุงวันที่ 6 กันยายน 2026

เกี่ยวกับระบบ

Hermes Studio เป็นเครื่องมือส่วนตัวที่ดูแลโดยเจ้าของ บัญชี GitHub kjkhunakorn ใช้จัดการไฟล์งานและสำรองข้อมูล ระหว่าง Oracle Cloud กับ Google Drive ไม่เปิดให้บุคคลทั่วไปสมัครใช้งาน

ข้อมูลที่เข้าถึงและวัตถุประสงค์

เมื่อเจ้าของบัญชีอนุญาต ระบบใช้ Google Drive API ผ่าน rclone เพื่อเข้าถึงข้อมูลไฟล์และโฟลเดอร์ เช่น ชื่อ รหัสไฟล์ ประเภท ขนาด และเวลาแก้ไข รวมถึงเนื้อหาไฟล์ที่จำเป็น สำหรับงานที่เจ้าของบัญชีสั่ง

การใช้งานครอบคลุมการอ่าน ดาวน์โหลด อัปโหลด จัดระเบียบ และสำรองไฟล์งาน เช่น เอกสาร สคริปต์ ภาพ เสียง และวิดีโอ ตลอดจนข้อมูลระบบที่เจ้าของเลือกสำรอง การลบไฟล์จะทำตามคำสั่งหรือนโยบายการเก็บที่เจ้าของอนุมัติ

ระบบขอสิทธิ์เท่าที่จำเป็นสำหรับความสามารถที่เปิดใช้ ขอบเขตสิทธิ์จริงจะแสดงในหน้าขออนุญาตของ Google การกำหนดโฟลเดอร์ทำงานไม่ได้หมายความว่า OAuth จำกัดสิทธิ์ไว้เฉพาะโฟลเดอร์นั้นเสมอไป

การจัดเก็บและการเข้าถึง

ไฟล์งานและชุดสำรองจัดเก็บใน Google Drive ของเจ้าของบัญชี เครื่อง Oracle อาจเก็บไฟล์ชั่วคราว ข้อมูลสถานะงาน และบันทึกการทำงานที่จำเป็น ข้อมูลอนุญาต OAuth จัดเก็บบนเครื่องที่รัน rclone และต้องจำกัดการเข้าถึงไว้สำหรับผู้ดูแลและโปรเซสที่จำเป็น

เว็บไซต์สาธารณะนี้เก็บเฉพาะข้อมูลแนะนำระบบและนโยบาย ไม่ใช่ที่เก็บไฟล์ Drive ชุดสำรอง หรือข้อมูลอนุญาต OAuth การเชื่อมต่อไม่เปลี่ยนไฟล์ Drive ให้เป็นสาธารณะโดยอัตโนมัติ

การส่งข้อมูลให้บริการอื่น

Google Drive และ Oracle Cloud ให้บริการจัดเก็บ และประมวลผลการรับส่งไฟล์ตามหน้าที่ของระบบ หากเจ้าของสั่งส่งลิงก์หรือไฟล์ผ่าน Telegram ข้อมูลที่เลือกส่งจะผ่านบริการ Telegram ด้วย

ในขอบเขตการเชื่อมต่อระยะแรก ไม่ส่งเนื้อหาที่อ่านจาก Google Drive ให้ผู้ให้บริการโมเดล AI หรือบริการสร้างสื่อ ก่อนเปิดความสามารถดังกล่าว ผู้ดูแลจะระบุผู้ให้บริการ ประเภทข้อมูล และวัตถุประสงค์ ปรับนโยบายนี้ และขอความยินยอมก่อนส่งข้อมูล

ไม่ขายข้อมูล Google ไม่ใช้ข้อมูลเพื่อกำหนดกลุ่มเป้าหมาย โฆษณา และไม่ใช้เพื่อฝึกโมเดล AI ทั่วไป การใช้และส่งต่อข้อมูลที่ได้รับจาก Google APIs ต้องเป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use ที่เกี่ยวข้อง

ระยะเวลาเก็บและการลบ

ไฟล์งานเก็บจนกว่าเจ้าของจะลบหรือกำหนดนโยบายการเก็บ ชุดสำรองเก็บตามตารางและอายุการเก็บที่เจ้าของอนุมัติ การลบไฟล์งานไม่ได้ลบสำเนาในชุดสำรองทันที เจ้าของต้องลบชุดสำรองที่เกี่ยวข้องหรือรอให้ครบอายุการเก็บ

สำเนาชั่วคราวที่ไม่จำเป็นจะถูกลบหลังตรวจการรับส่งไฟล์ ตามขั้นตอนที่กำหนด การลบถาวรอาจต้องจัดการถังขยะ และสำเนาอื่นในบริการที่เกี่ยวข้องด้วย

การยกเลิกสิทธิ์

เจ้าของสามารถเพิกถอนการเชื่อมต่อผ่าน หน้าการเชื่อมต่อบัญชี Google และนำข้อมูลอนุญาตออกจากเครื่อง Oracle การเพิกถอนสิทธิ์ไม่ลบไฟล์หรือสำเนาที่จัดเก็บไว้ก่อนหน้า

การเปลี่ยนแปลงและการติดต่อ

ผู้ดูแลจะปรับนโยบายเมื่อการใช้ข้อมูลเปลี่ยน และขอความยินยอมก่อนใช้ข้อมูลในวัตถุประสงค์ใหม่

ติดต่อผ่าน GitHub Issues ของโครงการ โดยไม่โพสต์ข้อมูลส่วนตัว รหัสผ่าน tokens หรือไฟล์ลับ
